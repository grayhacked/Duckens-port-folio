Data Science & Machine Learning

LightGBM · Forecasting · Snowflake · Cdiscount

Prévision des recherches à fort trafic

Pipeline LightGBM de prévision à 28 jours des recherches qui génèrent le plus de vues pendant les temps forts (Black Friday, soldes, French Days), livrant aux équipes Produit le top 1 500 des mots-clés à anticiper.

  • Méthode : retards de 1 à 365 jours, moyennes glissantes, distance aux événements, target encoding, cible en log, validation temporelle et early stopping
  • Résultat sur le jeu de test : WAPE 13,4 %, R² 0,77

Projet réalisé en entreprise : code et données confidentiels.

ARIMA · SARIMAX · XGBoost · FastAPI · Docker

Prévision météo de bout en bout

Projet de fin d’études ESTIA : comparaison d’ARIMA, SARIMA et SARIMAX à des modèles de régression (Random Forest, Gradient Boosting, XGBoost), avec recherche d’hyperparamètres en validation croisée, sélection de variables et analyse des résidus.

  • Mise en production : registre de modèles versionnés, API FastAPI de 10 endpoints
  • Qualité : tests pytest, CI GitHub Actions publiant l’image Docker

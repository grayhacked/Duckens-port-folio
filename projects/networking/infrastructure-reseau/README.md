# Infrastructure réseau documentée

## Objectif

Simuler et documenter une infrastructure réseau avec adressage IP, services, règles de sécurité et scénarios de diagnostic.

## À ajouter

- schéma réseau dans `screenshots/` ;
- configurations anonymisées ;
- procédure de test de connectivité ;
- résultats et incidents simulés ;
- lien vers le dépôt GitHub.

## Technologies

Linux, TCP/IP, outils de diagnostic réseau.

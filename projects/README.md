# Organisation des projets

Chaque projet possède son propre dossier afin de séparer le code, les données de démonstration, les captures et la documentation.

## Structure recommandée

```text
projects/
├── data-analytics/
│   └── nom-du-projet/
│       ├── README.md
│       ├── data/
│       ├── notebooks/
│       ├── src/
│       └── screenshots/
├── data-science/
└── networking/
```

## Fiche projet minimale

Chaque `README.md` doit expliquer :

1. le contexte et le problème ;
2. les données ou l'environnement de test ;
3. les technologies utilisées ;
4. l'installation et l'exécution ;
5. les résultats et les limites ;
6. le lien vers la démonstration, si elle existe.

Ne publie jamais de données clients, de mots de passe, d'adresses IP internes ou de fichiers confidentiels.

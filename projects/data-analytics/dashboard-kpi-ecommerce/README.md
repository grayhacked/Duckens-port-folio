# Dashboard KPI E-commerce

## Objectif

Créer un dashboard Power BI permettant de suivre le trafic, la conversion et l'engagement à partir de données publiques ou fictives.

## À ajouter

- capture du dashboard dans `screenshots/` ;
- modèle de données et mesures DAX ;
- source de données anonymisée ;
- lien vers le dépôt GitHub ;
- lien vers une démonstration publique si disponible.

## Technologies

Power BI, DAX, SQL.
